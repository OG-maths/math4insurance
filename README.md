# Mathematics for Insurance — Quarto site

This directory contains the source of the course website. The site is configured for British English and uses a restrained dark blue-grey theme defined in `custom.scss`. The page-level table of contents is disabled globally in `_quarto.yml`.

## Book-cover images

`reading.qmd` uses the six JPEG files in `images/`. PNG exports of the same local thumbnails are provided in `cover-exports/` for reuse in slides or documents.

The bundled images are clean bibliographic thumbnails created for this course site so that the project remains self-contained. They are **not scans of the publishers' jacket artwork**. If you prefer the original publisher covers, replace the JPEGs with images of the same filenames. Useful source pages are:
